Utils

Package: com.simulacao_terminal.utils

Description: Utility class for console operations. Provides methods for clearing the screen and resetting cursor position.

Overview

Utils contains helper methods for terminal manipulation using ANSI escape codes. These are essential for smooth console rendering in the GraphicEngine.

Constructor

Utils()

No-argument constructor. No initialization required.

Methods

clearConsole()

Description: Clears the entire console screen and moves cursor to top-left.

ANSI Sequence: \033[H\033[2J

  • \033[H - Move cursor to home position (1,1)
  • \033[2J - Clear entire screen

Usage: Call at game start to clear any previous output.

Utils utils = new Utils();
utils.clearConsole();
// Game output begins here

resetConsolePosition()

Description: Moves cursor to the top-left of the console without clearing.

ANSI Sequence: \033[H

Usage: Call before each frame render to overwrite previous output.

utils.resetConsolePosition();
System.out.print(currentFrame);
// Previous frame content is replaced

ANSI Escape Codes

CodeEffectUse Case
\033[HCursor homeReset to (0,0)
\033[2JClear entire screenFull clear

Platform Compatibility

ANSI escape codes work on:

  • Linux terminals (all)
  • macOS Terminal (all)
  • Windows 10+ Command Prompt and PowerShell
  • Modern terminal emulators (xterm, gnome-terminal, etc.)

For older Windows versions, consider adding a platform check or using JLine's built-in functionality.

Performance Note: Using System.out.print() directly (not println) with pre-built frame strings minimizes I/O calls and improves rendering performance.
