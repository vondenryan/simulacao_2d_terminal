MapController

Package: com.simulacao_terminal.controllers

Description: Handles terrain generation and player spawning. Uses Perlin noise for natural terrain generation with caves.

Overview

MapController provides procedural terrain generation with two modes: flat terrain and natural terrain with Perlin noise. It also handles finding valid player spawn positions.

Constructor

MapController()

No-argument constructor. No initialization required.

Methods

generateMap(int rows, int cols, int generationType)

Description: Generates a terrain map with the specified dimensions and generation type.

ParameterTypeDescription
rowsintNumber of rows (height) in the map
colsintNumber of columns (width) in the map
generationTypeint1 = flat, 2 = natural with Perlin noise

Returns: int[][] - 2D array representing the terrain map

Throws: Returns empty array for invalid generation type

spawnPlayer(int[][] map)

Description: Finds a valid spawn position for the player on the terrain surface.

ParameterTypeDescription
mapint[][]The generated terrain map

Returns: int[] - Array with [y, x] coordinates for player spawn

Algorithm:

  1. Picks a random X position (1 to width-1)
  2. Scans downward from top to find terrain surface
  3. Spawns on the first air/terrain boundary
  4. Falls back to mid-height if no surface found

Generation Types

Type 1: Flat Generation

Creates a simple flat terrain at the bottom half of the map. Randomly assigns grass or dirt blocks below the mid-point.

Type 2: Natural Generation

Creates natural terrain using Perlin noise:

  • Surface Scale (0.02): Controls terrain height variation
  • Cave Scale (0.05): Controls cave size and frequency
  • Ground Level: Determined by Perlin noise offset by 50% of map height
  • Layers:
    • Top 1 block: Grass (surface)
    • Next 4 blocks: Dirt (shallow)
    • Below that: Stone (deep)
  • Caves: Created where cave noise exceeds 0.68 threshold
Note: The random values are generated each call using Math.random(). For reproducible maps, you would need to fix the seed values in the generation logic.
