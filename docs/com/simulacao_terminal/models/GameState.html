GameState

Package: com.simulacao_terminal.models

Description: Holds shared game state including running status and last input. Designed for thread-safe access between InputController and InputService.

Overview

GameState acts as a communication channel between different game threads. It stores the global running state and the last keystroke received from the user.

Constructor

GameState(boolean running)

Description: Initializes the game state with a running status.

ParameterTypeDescription
runningbooleanInitial running state (true = game active)

Fields

FieldTypeAccessDescription
lastInputvolatile charPublicLast keystroke received. Declared volatile for visibility across threads.
target_fpsprivate intPrivateTarget frames per second (30)
frame_timeprivate intPrivateMilliseconds per frame (1000/30 ≈ 33ms)
fpsprivate intPrivateCurrent FPS value - currently unused
Thread Safety: The lastInput field is declared volatile to ensure that changes made by InputController are immediately visible to InputService. All writes use synchronized (gs) blocks, and reads use synchronized(gameState) blocks.

Usage Pattern

// In InputController (writer thread):
synchronized (gs) {
    gs.lastInput = c;
}

// In InputService (reader thread):
synchronized (gameState) {
    keyPressed = gameState.lastInput;
    gameState.lastInput = '\0';  // Clear after reading
}
