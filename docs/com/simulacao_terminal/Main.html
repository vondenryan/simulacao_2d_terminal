Main Class

Package: com.simulacao_terminal

Description: Entry point of the 2D terminal simulation. Initializes and starts all game components including the map, player, input controller, and rendering engine.

Overview

The Main class orchestrates the game startup process by:

  • Creating a MapController to generate terrain
  • Generating the world map with procedural terrain
  • Spawning the player at a valid position
  • Starting the InputController for keyboard handling
  • Starting the GraphicEngine for rendering
  • Starting the InputService for input processing

Game Loop

The game runs three concurrent threads:

  1. Input Controller Thread - Reads keyboard input and stores in GameState
  2. Graphic Engine Thread - Renders the game state to terminal
  3. Input Service Thread - Processes input and updates player physics

Example Usage

public static void main(String[] args) throws Exception {
    MapController mapController = new MapController();
    Utils utils = new Utils();

    // Generate terrain map
    int map[][] = mapController.generateMap(10000, 50000, 2);

    // Spawn player at valid position
    int pPos[] = mapController.spawnPlayer(map);
    Player player = new Player(pPos[1], pPos[0]);

    // Initialize game state
    GameState gameState = new GameState(true);

    // Start all systems
    InputController inputController = new InputController(gameState);
    inputController.start();

    GraphicEngine renderer = new GraphicEngine(map, player, gameState);
    utils.clearConsole();
    renderer.start();

    InputService inputService = new InputService(gameState, player, map);
    inputService.start();
}
