PerlinNoise

Package: com.simulacao_terminal.utils

Description: Implementation of Perlin noise algorithm for generating smooth random terrain. Used by MapController for natural terrain generation with caves.

Overview

This is a standard Perlin noise implementation that generates coherent noise values for smooth terrain. Perlin noise creates values that vary smoothly, making it ideal for generating natural-looking terrain features.

Algorithm Overview

The algorithm works by:

  1. Computing a gradient vector at each lattice point
  2. Computing a dot product with the distance from lattice point to query point
  3. Smoothing the contributions using a fade function
  4. Linearly interpolating between adjacent lattice values

Static Fields

FieldTypeDescription
pint[512]Padded permutation table for noise generation
permutationint[256]Original permutation values

The permutation table is padded with duplicate values to avoid modulo operations during noise calculation.

Methods

noise(float x, float y)

Description: Computes 2D Perlin noise for the given coordinates.

ParameterTypeDescription
xfloatX coordinate in noise space
yfloatY coordinate in noise space

Returns: float - Noise value in range [-1.0, 1.0]

fade(float t)

Description: Smooth interpolation curve (fade function). Returns 0 for t=0 and 1 for t=1, with zero derivatives at both ends.

ParameterTypeDescription
tfloatInput value between 0 and 1

Returns: float - Smoothed value

Formula: t * t * t * (t * (t * 6 - 15) + 10)

lerp(float t, float a, float b)

Description: Linear interpolation between two values.

ParameterTypeDescription
tfloatInterpolation factor (0 = a, 1 = b)
afloatStart value
bfloatEnd value

Returns: float - Interpolated value: a + t * (b - a)

grad(int hash, float x, float y)

Description: Computes gradient dot product for a lattice point.

ParameterTypeDescription
hashintHash value from permutation table
xfloatX distance from lattice point
yfloatY distance from lattice point

Returns: float - Dot product of gradient and distance

Usage in MapController

// Surface height generation
float surfaceScale = 0.02f;
double offsetX = Math.random() * 300;
double offsetY = Math.random() * 300;

int groundLevel = mapHeight / 2 + (int)(PerlinNoise.noise(
    (float)(offsetX + (x * surfaceScale)),
    0.6f
) * 8);

// Cave generation
float caveScale = 0.05f;
float caveNoise = (PerlinNoise.noise(cX, cY) + 1.0f) / 2.0f;
if (caveNoise > 0.68f) {
    m[y][x] = 0;  // Cave air
}

Scale Parameters

ParameterValueEffect
surfaceScale0.02fControls terrain height variation frequency
caveScale0.05fControls cave size and frequency

Smaller scale values = larger features, larger scale values = smaller features.

Range Mapping

The noise function returns [-1, 1]. Common mappings:

Use CaseMappingResult Range
Ground level(noise + 1) * 8[0, 16]
Cave threshold(noise + 1) / 2[0, 1]
Note: This is a deterministic implementation - same coordinates always produce the same noise value. Random offsets (offsetX, offsetY) provide variety across game sessions.
