Package Structure

com.simulacao_terminal (Main Package)

  • Main - Entry point. Initializes and starts all game components.

com.simulacao_terminal.controllers (Controller Package)

  • InputController - Keyboard input handling using JLine. Runs in separate thread.
  • MapController - Terrain generation with Perlin noise and player spawning.

com.simulacao_terminal.models (Model Package)

  • GameState - Shared game state including running status and last input.
  • Player - Player entity with position, velocity, and physics properties.

com.simulacao_terminal.services (Service Package)

  • InputService - Processes keyboard input and applies physics to player.

com.simulacao_terminal.engine (Engine Package)

  • GraphicEngine - Handles rendering and physics simulation. Runs dual threads.

com.simulacao_terminal.utils (Utility Package)

  • PerlinNoise - Perlin noise algorithm for terrain generation.
  • Utils - Console utility methods (clear, reset position).

Quick Start

public static void main(String[] args) throws Exception {
    MapController mapController = new MapController();
    Utils utils = new Utils();

    // Generate terrain
    int map[][] = mapController.generateMap(10000, 50000, 2);

    // Spawn player
    int pPos[] = mapController.spawnPlayer(map);
    Player player = new Player(pPos[1], pPos[0]);

    // Initialize game state
    GameState gameState = new GameState(true);

    // Start systems
    InputController inputController = new InputController(gameState);
    inputController.start();

    GraphicEngine renderer = new GraphicEngine(map, player, gameState);
    utils.clearConsole();
    renderer.start();

    InputService inputService = new InputService(gameState, player, map);
    inputService.start();
}

Architecture

The game runs three concurrent threads:

  1. Input Controller - Reads keyboard, writes to GameState
  2. Input Service - Reads from GameState, modifies Player velocity
  3. Graphic Engine - Updates physics, renders map
