InputController

Package: com.simulacao_terminal.controllers

Description: Handles keyboard input using JLine terminal library. Runs in a separate thread and stores input in GameState.

Overview

InputController uses JLine's TerminalBuilder to capture raw keyboard input without requiring Enter to be pressed. It runs continuously while the game is running and stores each keystroke in the shared GameState.

Constructor

InputController(GameState gameState)

Description: Initializes the input controller with a reference to the game state.

ParameterTypeDescription
gameStateGameStateThe shared game state object where input will be stored

Methods

start()

Description: Starts the input reading thread. This method returns immediately while input continues to be read in the background.

Thread Safety: The input is written to GameState with proper synchronization using synchronized (gs) blocks.

readInputs()

Description: Main input reading loop. Reads keystrokes from the terminal and stores them in GameState.

Behavior:

  • Continues while running == true and gameState.isRunning() == true
  • Reads keystrokes one at a time using reader.read()
  • Converts integer code to char for storage
  • Escape key (27) sets running to false and exits
  • All other keystrokes are stored in GameState.lastInput

restoreTerminal()

Description: Restores the terminal to normal mode on shutdown. Called automatically when the input thread exits.

Keyboard Input Mapping

KeyValueHandler
Escape27Quits the game
W / ↑'w' or 'W'InputService - Jump
A / ←'a' or 'A'InputService - Move Left
D / →'d' or 'D'InputService - Move Right
Space' 'InputService - Jump
Note: The lastInput field in GameState is declared volatile to ensure visibility across threads. The input controller synchronizes writes, and InputService synchronizes reads.

Exception Handling

The input reader catches all exceptions and prints the stack trace. The terminal is always restored in the finally block.
