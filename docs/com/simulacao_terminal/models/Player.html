Player

Package: com.simulacao_terminal.models

Description: Represents the player entity with position, velocity, and physics properties. Handles movement, jumping, and collision with terrain.

Overview

The Player class encapsulates all player state including 2D position, velocity, and physics constants. It works with the GraphicEngine and InputService to move and render the player character.

Player(float startX, float startY)

Description: Creates a new player at the specified position.

Returns: int - X coordinate as integer grid position

Physics Constants

ConstantValueDescription
GRAVITY0.2fDownward acceleration added each frame

ACCELERATION0.9fVelocity added when moving per frame
DECELERATION0.4fVelocity removed when no key pressed

Velocity Limits

The GraphicEngine enforces maximum velocity limits in the physics update:

VelocityMinMax
velX-1.8+1.8
velY-1.8+1.8

Usage Pattern

// Player initialization
Player player = new Player(startX, startY);

// Physics is updated by GraphicEngine
// InputService modifies velocity based on keys
if (key == 'd') {
    player.velX += player.ACCELERATION;  // Move right
} else if (key == ' ') {
    if (player.onGround) {
        player.velY = player.JUMP_POWER;  // Jump
    }
}

Rendering

The player is rendered as a red circle O at the grid position returned by getGridX() and getGridY().

Note: Position is stored as float for smooth movement but rounded to integer for collision detection and rendering.
